Stock management software

For my assignment I decided to use the observer pattern as the majority of the logic behind my task is to listen to and get updated on changes in the stock market and that is the primary intent of the observer pattern. The observer pattern is designed to allow many listeners to subscribe to the single object so that fits with the three different parts the this task (real-time display, alert system, statistics module). The observer pattern also allows the subject to not make assumption of the subscribers preventing the subscribers from being tightly coupled. The observer pattern is the default pattern to handle notifications and updates when software needs to listen to the state of a component of a system ie my stock service being listened to by my three different observer instances in the example.
